一个好用的小工具，常常来自一个重复出现的小麻烦。比如每次调试接口，都要手动整理一段 JSON。

## 从具体的问题出发

把“做一个开发工具箱”缩小成“粘贴 JSON，看到格式化结果”。目标越具体，越容易验证它是否有用。

## 先完成最短路径

第一版只保留输入、处理和反馈三个步骤。处理成功时展示结果，失败时给出可以理解的提示。

```js
try {
  const value = JSON.parse(input);
  const formatted = JSON.stringify(value, null, 2);
  console.log(formatted);
} catch {
  console.log('请检查 JSON 格式');
}
```

## 把边界也当作功能

- 输入为空时，应该告诉用户发生了什么。
- 失败后保留原始输入，方便修正。
- 不需要上传的数据，就留在浏览器里处理。

## 做完之后再打磨

先让工具真正解决问题，再改进快捷键、排版与复制体验。你可以到本站的[作品页](/projects/json-workbench)体验一个简化版本。
