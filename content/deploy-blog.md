本地运行成功，是部署的起点。让网站稳定运行，还需要明确环境、进程与数据的位置。

## 区分源码与数据

源码可以通过 Git 更新；评论数据库和环境变量需要独立保存。不要让一次发布覆盖用户内容。

```text
blog/
  app/          页面与接口
  content/      Markdown 文章
  data/         评论数据库，不进入 Git
  .env.local    本地配置，不进入 Git
```

## 先验证生产构建

开发模式和生产模式不同。在发布前运行构建，确认页面与接口可以正常启动。

```bash
pnpm install --frozen-lockfile
pnpm build
pnpm start
```

## 让 Nginx 处理入口

应用监听本机地址，由 Nginx 接收访客请求并转发。后续绑定域名时，再修改网站入口、站点地址及授权回调地址。

## 给数据留一份备份

数据库备份应使用一致性快照。恢复演练与备份同样重要：确认备份真的能被读取，才算完成这个环节。
